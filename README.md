# How They Built the Pyramids — In-Game Trainer

In-game trainer for How They Built the Pyramids: edit Player & Shabti stats, add money, spawn Gold/Engraved blocks, Unlimited Carry & No Heat.

## Features

- **Player Stats & Upgrades**: Edit Speed & Strength levels, plus ExtraHands, LongArms, GymGear, ClayBucket, and HandFan upgrades.
- **Shabti Stats**: Edit Strength, Speed, Stamina, and Skill for individual Shabti or all Shabti at once.
- **Money**: Add `+1000` team money with one click or hotkey.
- **Golden Blocks**: Spawn `+10`, `+100`, `+500`, or any custom amount directly into your hands.
- **Engraved Golden Blocks**: Spawn `+10`, `+100`, `+500`, or any custom amount of engraved golden blocks.
- **Unlimited Carry**: Remove block carry limit and carry movement/jump penalties.
- **No Heat Required**: Disable overheating and fainting.

## Installation

1. Copy the `Trainer` folder (`PyramidTrainer.dll`, `PyramidTrainerInjector.exe`) and `Start_Trainer.bat` into the game's root directory (next to `Pyramid.exe`).
2. No original game files are modified.

## Usage

1. Run `Start_Trainer.bat` (it will launch `Pyramid.exe` automatically, or inject into it if already running).
2. Enter a world/save in-game.
3. Press **`F1`** or **`Insert`** to open/close the trainer menu.

## Hotkeys

| Key | Action |
| --- | --- |
| `F1` / `Insert` | Toggle Trainer Menu |
| `F2` | `+1000` Money |
| `F3` | `+10` Golden Blocks |
| `F4` | `+10` Engraved Golden Blocks |
| `F5` | Toggle Unlimited Carry |
| `F6` | Toggle No Heat Required |

> **Note:** Works in singleplayer or when acting as the multiplayer host.
